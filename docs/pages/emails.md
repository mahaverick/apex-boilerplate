# Emails

The sent-email log (`/emails/`) and one email's page (`/emails/$emailId`). Back to the [route map](README.md#route-map).

|                     |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| File                | `src/pages/_app/emails/index.tsx`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

| Data                | `GET /platform/emails?search&status&template&user&tenant&from&to&sort&cursor&direction&limit&total=1` (`['platform', 'emails', 'list', request]`), started by the loader; the previous view's rows stay up while the next loads. A user or tenant filter chip whose name is not on the page reads `GET /platform/users/:id` or `GET /platform/tenants/:id`.                                                                                                                                                       |
| Sections            | The `h1`, then `DataTable`: a toolbar with "Search by recipient" (debounced into `?search`), facets Status and Template (comma lists in `?status`, `?template`), `DateRangeFilter` (a `Popover` with a range `Calendar`, `?from` `?to`; an inverted range in the URL is dropped), Columns and a result count; under it, removable chips for the picked values and for `?user` and `?tenant` when set. | Transitions         | a recipient → `/emails/$emailId`; a user → `/users/$userId`; a tenant → `/tenants/$tenantId`; Previous/Next → `?cursor` (and `?direction=prev` going back)                                                                                                                                                                                                                                                                                                                                                        |

The User column repeats the recipient's address for most rows, since an email to an account goes to its address.

### `/emails/$emailId` — Email

![Email](img/emails/email-detail--default.jpg)

|                     |                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Purpose             | One email: who it went to, how it stands, its delivery timeline and a rendered preview; resend when the API allows.                                                                                                                                                                                                                                                                                 |
| File                | `src/pages/_app/emails/$emailId.tsx`                                                                                                                                                                                                                                                                                                                                                                |
| Guard and redirects | `_app`. A 404 renders an `EmptyState` with the `h1` "Email not found" and Back to emails. `?tab=timeline\|preview`.                                                                                                                                                                                                                                                                                 |
| Layout              | `AppLayout`                                                                                                                                                                                                                                                                                                                                                                                         |
| Data                | `GET /platform/emails/:id` (`['platform', 'email', id]`), started by the loader. On the Preview tab, `GET /platform/emails/:id/preview` (`['platform', 'email', id, 'preview']`). Resend posts through `ReasonDialog`.                                                                                                                                                                              |
| Sections            | Header: the recipient as the `h1`, the template, status badge, sender class and created time, links to the user and the tenant, the failure reason for a failed email, and **Resend** (when `canResend`). A suppression note when the address is suppressed, with View suppression. `Tabs`: Timeline (`EmailTimeline`, an `ol` of events) and Preview (the rendered email in a sandboxed `iframe`). |
| Components          | `Tabs`, `Badge`, `Button`, `Skeleton`, `CardRowsSkeleton`, `EmptyState`, `LoadError`, `RoleDenied`, `QueryState`, `ReasonDialog`, `EmailTimeline`, `EmailPreviewPanel`, `Note` (warning: the suppression note and the preview's placeholders note; info: the template-unavailable note)                                                                                                             |
| Transitions         | the user → `/users/$userId`; the tenant → `/tenants/$tenantId`; View suppression → `/suppressions?search=`                                                                                                                                                                                                                                                                                          |

While the message loads, the page is a visually hidden `h1` "Email", a three-line header (`h-8 w-80`, `h-5 w-64`, `h-5 w-48`), one `h-9 w-44` pill for the two-tab list and a timeline of four `2rem` rows; the timeline's length varies when loaded, so that part is a guess. A failed refetch of the message keeps the page with a `LoadError` above it; a 404 still replaces it. The preview reads through `QueryState`: the `h-160` skeleton stays (the frame's real height), a failure is a `LoadError` "We couldn’t load the preview. Select Try again." with Try again, a 404 is `RoleDenied`, and the 409 `template_unavailable` answer keeps its own note above `QueryState`, because it is not a role refusal.
